Expense Tracker
A responsive web-based Expense Tracker built using HTML, CSS, and JavaScript. The application helps users manage income and expenses, view transaction history, filter transactions, and analyze their spending through interactive charts.
Features
- Add income and expense transactions
- Record amount, category, date, and description
- View total income, total expenses, and current balance
- View the latest 5 transactions on the dashboard
- View complete transaction history
- Filter transactions by type and category
- Delete transactions
- Store transaction data using Browser Local Storage
- Monthly income and expense analysis
- Cash flow analysis
- Monthly savings analysis
- Expense breakdown by category
- Responsive design for desktop, tablet, and mobile devices
- No account or backend required
Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage API
- Chart.js

How It Works
Add Transactions
Users can add:
- Income or Expense
- Amount
- Category
- Date
- Description
Dashboard
The dashboard displays:
- Total Income
- Total Expenses
- Current Balance
- Recent Transactions
Transaction History
The Transaction History page allows users to view all saved transactions and filter them by:
- Income / Expense
- Category
Transactions can also be deleted.
Analytics
The application provides visual insights including:
- Monthly Income vs Expenses
- Cash Flow
- Money Saved Each Month
- Expense by Category
Data Storage
Transaction data is stored in the browser using the Local Storage API.
The data remains available after refreshing or reopening the browser on the same device and browser.
No external database or backend server is required.
Getting Started
